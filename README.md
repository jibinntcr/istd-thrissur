# ISTD Thrissur Chapter — Official Website

> **Indian Society for Training & Development (ISTD) — Thrissur Chapter, Kerala, India**  
> Promoting excellence in Human Resource Development, workplace learning, leadership, and professional certifications across Central Kerala.

---

## 🌟 Overview

This repository contains the official website for the **ISTD Thrissur Chapter**, affiliated with the national body of the Indian Society for Training & Development (established in 1970, New Delhi).

The website is crafted with a modern, high-contrast, clean 2D vector line-art design aesthetic, optimized for fast performance, accessibility, and mobile responsiveness.

---

## ✨ Key Features & Architecture

- **Clean 2D Vector Illustration Language**: Custom minimal line-art illustrations with thin black outlines, generous white space, soft pale-blue backdrops, and vibrant red/blue/yellow accents.
- **Illustrated Leadership Team**: Custom vector portrait avatars for all office bearers and committee members.
- **Mobile-First Experience**: 
  - Offcanvas hamburger navigation drawer with backdrop blur.
  - App-style floating bottom quick-action bar for mobile devices (`Call`, `Join`, `Programs`, `Contact`).
- **Interactive Components**:
  - Dynamic animated impact statistics counters.
  - Testimonial quote carousel with touch swipe support.
  - Validated lead generation & membership enquiry forms.
- **Zero-Dependency Architecture**: Built with modern Vanilla HTML5, CSS3 Custom Properties (Design Tokens), and lightweight Vanilla JavaScript.

## 🚀 Getting Started

### Local Preview

You can open any `.html` file directly in your browser, or run a local static web server:

```bash
# Using Python 3
python3 -m http.server 8080

# Or using Node.js (npx serve)
npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your web browser.
